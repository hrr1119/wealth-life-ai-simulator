# 首版验收映射

## 可玩性

| 规格要求 | 当前实现 | 验证方式 |
| --- | --- | --- |
| 不读长教程也能完成一局 | 开局只需模式、身份、主题；主界面只展示路线、现金流、行动 | 首屏与帮助卡 |
| 至少三次结果明显不同 | 世界种子、宏观周期、事件权重、隐藏天赋、概率落点 | 确定性测试 + 随机新局 |
| 无单一必胜路线 | 投资模拟波动/流动性，转行需要技能与成本，多线占用时间 | 规则层 |
| 过去行为改变未来 | 本回合行动会改变事件候选；人生记忆、路线节点、天赋样本、信用/关系/健康状态进入后续裁决 | 规则层、事件导演与局末复盘 |
| 职业路线具有连续故事 | 20 个职业事件组成成长、冲击、转型、独立经营四条支线，前序选择决定后续入口 | 内容数量与完整回合测试 |

## AI 与规则

| 规格要求 | 当前实现 | 验证方式 |
| --- | --- | --- |
| 自然语言转结构化机会卡 | `/api/opportunity` 返回 3 张 `OpportunityCard` | 自动测试 |
| AI 不直接改数值 | 机会卡没有 `effects`；只有 `resolveOpportunity` 可改状态 | 自动测试 |
| 不合理愿望被拆成现实步骤 | 低成本试水、系统化建设、合作伙伴三个约束方案 | 自由机会界面 |
| 关键结果可追溯 | `ProbabilitySnapshot` 保存基础、修正、落点和解释 | 规则快照弹窗 |

## UI

| 规格要求 | 当前实现 |
| --- | --- |
| 首屏看到路线、现金流、可选行动 | 桌面棋盘 + 右侧控制台 + 固定行动坞 |
| 棋盘是视觉核心 | 职业与能力、现金与资产、关系与生活三条动态路线；只有真实行动/事件能生成节点，失败会留下疤痕，候选分岔显示解锁状态 |
| 卡牌桌面与手机可读 | 事件卡与选择卡响应式重排 |
| 四主题不改变结构 | 深绿金色、午夜蓝紫、暖白纸张、赤陶橙黑 |
| 不是普通后台 Dashboard | 采用实体桌游材质、路线节点、卡牌台和规则印章语言 |
| 回合严格遵循规格书 | 世界观察 → 普通行动 → 玩家互动 → 宏观事件 → 个人事件 → 统一结算 → 学习反馈；七个独立场景依次推进 |
| 事件触发可解释 | 个人事件卡显示命中的本回合行动、故事包阶段和世界周期原因 |

## 复盘

| 规格要求 | 当前实现 |
| --- | --- |
| 引用真实行动和最终数据 | 从 `history`、路线节点、资产、负债、健康和技能生成 |
| 解释相关知识模型 | 只输出本局实际触发的知识模型 |
| 区分运气、准备和决策 | 概率快照与局末归因比例 |
| 不简单判定成功/失败 | 决策画像 + 优势 + 脆弱点 + 关键转折 |
| 回放长期因果 | 按职业/资本/生活三条路线输出“早期选择 → 后续节点 → 结果证据” |

## 自动检查

- 内容最低数量。
- 世界种子确定性。
- 自由机会结构边界。
- 行动资源消耗与审计记录。
- 投资状态变化。
- 七阶段回合状态机及事件延迟到正确阶段。
- 路线图只因行动生长，旧版存档可迁移。
- 不同行动改变事件导演候选列表。
- 20 个职业故事事件、4 条故事支线和 4 位独立 AI 角色。
- 局末报告包含真实路线因果链。
- 12 年从开局到复盘完整闭环。

## 当前版本边界

账号与跨端存档、内容运营后台仍属于后续阶段。当前版本已实现 2–4 人持久化联机房间、断线 AI 接管与重连、60 年深度人生和长期企业/家庭/保障系统；多人回合按“秘密普通行动 → 玩家互动/合同 → 共同揭晓与学习反馈”推进。
