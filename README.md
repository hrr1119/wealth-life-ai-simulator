# 财富人生

AI 驱动的开放式人生财商模拟游戏。产品采用“精致桌游棋盘 + 现金流控制台 + 卡牌事件台”的核心界面，由本地规则引擎裁决结果，AI 仅负责把自然语言想法生成受约束的机会卡。

## 在线体验

**[打开财富人生](https://hrr1119.github.io/wealth-life-ai-simulator/)**

也可以使用包含完整服务端能力的 **[财富人生公开站](https://wealth-life-ai-sim.q1658046672.chatgpt.site/)**。

公开体验无需注册、无需密码；单人存档仅保存在当前浏览器。自然语言“自由机会”在静态版中使用本地规则映射，因此即使没有后端接口也能完整游玩。全栈部署配置服务端密钥后会优先调用真实 AI，接口不可用时自动回退到同一套本地规则。GitHub Pages 与公开站的多人入口都会连接同一套持久化房间服务。

## 当前交付

- **三种完整模式**：12 年快速模式、24 年标准模式，以及已经解锁的 60 年 / 240 季度深度人生。
- **规格书七阶段回合**：世界与个人状态 → 普通行动 → 玩家互动 → 宏观事件 → 个人/关系事件 → 资产与状态结算 → 学习反馈；每一阶段都有独立桌面场景，不再用同一套页面反复揭晓。
- **动态人生棋盘**：职业与能力、现金与资产、关系与生活三条路线会按真实状态推进和分岔；自由机会是可进入的特殊路径，不是装饰性固定环线。
- **三年人生章节**：起步、探索、扩张、承压、转型与收获阶段会生成独立章节总结和路线解锁。
- **独立世界**：世界种子、城市、经济周期、利率、通胀、行业趋势。
- **多线人生**：30 条职业路线、48 项技能、24 类资产、36 个事件原型。
- **自由机会**：自然语言输入 → 3 张现实机会卡 → 规则引擎裁决 → 概率快照。
- **真实 AI 边界**：OpenAI 只理解语义并生成经 JSON Schema 约束的策略文本；成本、耗时、概率和最终数值始终由规则引擎计算。
- **长期因果**：人生记忆、隐藏天赋样本、技能组合、时代适配、可到期延迟后果与三阶段职业事件链。
- **财务闭环**：主动收入、被动收入、支出、负债、资产估值、利息、应急金。
- **长期人生闭环**：季度规划与结算、累进税与年末汇算、保险保额与保费、养老金个人缴费/雇主匹配、房贷摊还与再融资、配偶共同财务、子女教育金与父母照护、企业员工/库存/现金/治理、遗嘱与代际评分。
- **社会闭环**：3 位拥有性格、目标、财务状态、信任、底线和长期记忆的 AI 同桌角色；可以请求帮助、先提供帮助、联合项目或重谈条件。
- **真实多人房间**：2–4 人通过 6 位邀请码加入同一网络房间；先秘密完成普通行动，再进入玩家互动与合同窗口，随后统一翻开宏观影响、个人结果和学习反馈。房间状态由 D1 持久保存，断线席位会自动由 AI 接管，持有原身份的玩家重连后恢复控制。
- **复盘闭环**：真实行动、关键转折、财务韧性、行为画像、运气/准备/决策归因。
- **产品能力**：4 套主题、响应式布局、自动本地存档、继续游戏、重新开始。

## 本地运行

项目需要 Node.js 22+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

打开开发服务输出的本地地址。

如需在全栈部署中启用真实 AI，在服务端设置环境变量：

```bash
OPENAI_API_KEY=your_server_side_key
OPENAI_MODEL=gpt-5-mini
```

密钥不会发送到浏览器；未配置密钥、请求超时或输出校验失败时会自动使用本地规则生成器。

若要预览与 GitHub Pages 完全一致的纯静态版本：

```bash
pnpm build:share
pnpm exec vite preview --config vite.share.config.ts
```

## GitHub Pages 发布

推送到 `main` 后，`.github/workflows/deploy-pages.yml` 会自动：

1. 安装锁定版本的 Node.js 与 pnpm 依赖。
2. 运行测试、类型检查和代码检查。
3. 构建 `share-dist/` 静态版本。
4. 发布到 GitHub Pages。

若需要回滚，在 GitHub 中回退 `main` 到之前的提交并重新运行该工作流即可。单人模式不依赖服务端 API，GitHub Pages 故障时仍可用任意静态主机托管 `share-dist/`；多人入口需要连接公开站的房间服务。

## 架构

```text
自然语言输入 ──> 机会理解器 ──> 结构化机会卡
                                      │
年度计划 ──> 行动队列 ─────> 规则/概率引擎 ──> 逐项揭晓、数值、记忆、审计快照
                                      │
世界种子 ──> 宏观/行业/事件选择 ───────┘
                                      │
人物目标/信任/底线 ──> 独立回应 ───────┤
                                      │
                                      └──> 延迟后果、三年章节与局末复盘

好友邀请 ──> D1 持久房间 ──> 同时规划 ──> 共同揭晓
                                      │
匿名身份令牌 ──> 断线恢复 / AI 接管 ──> 谈判交易 ──> 统一结算
```

核心边界：

1. `lib/opportunity.ts` 只生成候选卡，不修改游戏状态。
2. `lib/ai.ts` 只允许模型生成语义策略，JSON Schema 与服务端映射会拒绝越界数值。
3. `lib/engine.ts` 是数值与概率的唯一裁决层。
4. `app/api/opportunity/route.ts` 根据环境配置选择 OpenAI 或本地回退，并保持输出结构不变。
5. `share/` 是公开静态入口；它会直接使用本地机会映射，避免在 GitHub Pages 上产生无效 API 请求。
6. 浏览器本地保存只承担单人存档与匿名房间身份；多人房间、玩家席位和交易记录以 D1 为权威来源。
7. `worker/multiplayer.ts` 在边缘运行房间状态机，规划阶段不会向其他玩家泄露行动；数值只在服务端统一结算一次。

详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，验收映射见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

## 目录

```text
app/
  api/opportunity/route.ts   # 受约束的自由机会接口
  multiplayer.tsx            # 创建/加入房间、同时规划、谈判与断线状态
  page.tsx                   # 开局、棋盘、事件、行动、复盘
  globals.css                # 四主题设计系统与响应式布局
lib/
  content.ts                 # 职业、技能、资产、事件、知识模型
  engine.ts                  # 世界、概率、结算、长期因果与复盘
  ai.ts                      # 服务端真实 AI 适配与结构化输出校验
  opportunity.ts             # 自然语言意图到机会卡的本地模拟器
  multiplayer.ts             # 多人共享类型、行动边界与公开 API 地址
  types.ts                   # 可扩展领域模型
worker/
  multiplayer.ts             # D1 房间、身份验证、同时规划、交易与 AI 接管
db/
  schema.ts                  # 多人房间、玩家席位和交易表
tests/
  engine.test.mjs            # 规则层自动测试
```
